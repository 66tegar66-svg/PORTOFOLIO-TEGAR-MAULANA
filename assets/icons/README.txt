ICON PLACEHOLDERS

These files are intentionally simple placeholders so you can replace them with your preferred official logos later.

Keep the same filenames so you do NOT need to edit the HTML:
- lua.svg
- java.svg
- python.svg
- javascript.svg
- html.svg
- css.svg
- php.svg
- database.svg
- github.svg
- linkedin.svg
- instagram.svg
- whatsapp.svg
- email.svg
- discord.svg

Recommended format: SVG or transparent PNG. If you switch from .svg to .png, update the src path in the HTML.
Recommended square canvas: 128x128 or 256x256.
