Discord Auto Store

RoleDeveloper / System Builder
TypeDiscord Store Automation
FocusProduct, Stock, Balance, Purchase
StatusIndependent Source Code
[ Overview ]

A storefront that lives inside Discord.

This project explores how a digital store can be operated through a Discord bot-style interface. The showcased flow includes product listings, stock and sold counters, registration, top-up, balance, purchasing and deposit actions.

The project reflects my interest in automation: reducing repetitive manual actions into a clear command-driven workflow while keeping the interface familiar to Discord users.
